# TWS Audio Relay

Локальный проект для передачи звука с компьютера на iPhone по Wi-Fi через браузер.

## Как это работает

- Компьютер открывает сайт как источник.
- iPhone открывает сайт как приемник.
- Локальный Node-сервер нужен для страницы, комнаты и обмена WebRTC-сообщениями.
- Сам звук идет напрямую между устройствами.

## Быстрый запуск

1. Запусти [start-local.command](/Users/a1/Projects/tws-audio-relay/start-local.command)
2. На компьютере выбери режим `Я на компьютере`
3. Отсканируй QR-код с iPhone
4. На компьютере нажми `Транслировать вкладку / системный звук`
5. На iPhone нажми `Подключиться и включить звук`

Теперь iPhone открывает отдельную облегчённую страницу-приемник `listener.html`, чтобы Safari меньше спотыкался о совместимость.

## Если iPhone не открывает страницу

- Сначала заново запусти [start-local.command](/Users/a1/Projects/tws-audio-relay/start-local.command). Теперь он поднимает сервер в фоне и ждет готовности.
- Убедись, что ПК и iPhone подключены к одной Wi-Fi сети.
- Открывай на iPhone не `localhost`, а адрес из QR-кода или сетевой адрес вида `http://192.168.x.x:4312`.
- Если нужно остановить локальный сервер, используй [stop-local.command](/Users/a1/Projects/tws-audio-relay/stop-local.command).

## Ограничения

- Оба устройства должны быть в одной Wi-Fi сети.
- На Windows через Chrome/Edge обычно лучше всего работает захват вкладки или экрана с включенным системным звуком.
- На macOS браузеры чаще дают звук вкладки, а не весь системный выход.
- Если нужен именно полный системный звук на macOS, обычно используют виртуальное аудиоустройство вроде BlackHole, но оно в этот проект не включено.
